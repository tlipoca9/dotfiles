# 系统标签、策略与治理能力

## 自定义标签、系统标签与创建者标签

自定义标签由用户创建和管理。系统标签由腾讯云系统创建、绑定和解绑，用户可见但不可编辑；系统标签不占用户标签数量和标签配额。系统标签键需要预先注册，资源或关系删除时由执行绑定的产品完成解绑闭环。

创建者标签是系统标签的一种自动化场景：用户启用后，资源创建时自动记录创建主体，可用于授权与分账；禁用通常只阻止新资源继续绑定，不会自动解绑已有资源。用户不能自行创建、修改或删除创建者键值。当前接口、白名单和产品支持范围读取 `4012867269`。

## 标签策略

标签策略约束或引导允许使用的标签键值，并可影响 SDK 中的优先展示和禁止删除行为。单账号模式面向主账号对子用户的约束；多账号模式面向集团管理账号对成员账号的治理。多个策略绑定到同一目标时，系统会生成最终有效策略，不能只看其中一条绑定策略判断效果。

自研大账号使用标签策略优化六类治理标签的选择与补齐，但来源系统仍不同：负责人类来自账号/企微链路，运营产品和运营部门来自 OBS，一级/二级业务来自各 BG 或公司的 CMDB。Tag 是这些数据的下游，不应把标签侧展示误认为权威源头。

## 配额、限制、继承和标签组

- 标签配额、标签限制、继承支持进度和标签组均高度易变；根树中的“标签配额”和“标签组”当前是空正文目录页。
- 配额接入细节存在于强制打标签/标签隔离等直接依赖中；当前数值、冻结时长和接口字段必须回源。
- 标签限制文档主要指向官网和体验白名单，当前能力以官网为准。
- 标签继承文档只提供企微需求文档和支持进度表入口；不要凭本地摘要断言某产品已支持。

## 项目兼容

项目管理是历史能力，与标签存在兼容层。项目数量、`ProjectId` 语义、保留键和自研特殊白名单会变化；需要具体解释时加载 `auth-resource-model.md` 并回源 `4016222015`。
