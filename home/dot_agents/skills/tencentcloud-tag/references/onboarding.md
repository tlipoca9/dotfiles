# 云产品首次接入与上线验证

## 稳定知识

标签接入承载三类主要能力：资源聚合管理、基于标签的 CAM 授权，以及按标签分账。云产品只需接入标签平台一次；国内站和国际站使用同一套云 API 参数，但调用域名可能不同。

接入前的关键前提是资源相关 Action 已按资源级接入 CAM。操作级或服务级授权无法支撑标签资源级鉴权。标签侧与 CAM 侧登记的 `serviceType`、`resourcePrefix` 和资源六段式语义必须一致。

一个完整接入通常涉及：

1. 确认产品、资源类型、地域模型、CAM 授权粒度和现有控制台/API 能力。
2. 在标签配置后台登记产品、资源、地域、查询列表 API、参数映射和跳转路径。
3. 在资源创建入口允许选择标签，创建 API 接收标签；资源列表和详情展示标签并支持筛选、单个/批量编辑。
4. 资源创建后完成绑定；资源删除后完成解绑。存在关联资源时评估标签继承，否则按标签授权的用户可能看不到间接创建的资源。
5. 按需接入系统标签、创建者标签、标签配额、分账映射和标签订阅。
6. 验证后再发布，并确保测试和现网配置语义一致。

## 验证知识

测试应覆盖控制台和 API 两种操作方式，以及云产品入口和标签控制台入口：

- 创建资源时选择已有标签和新标签；强制标签、标签策略、创建者标签、配额按适用能力验证。
- 资源列表、详情、标签列表和资源标签列表看到的绑定关系一致。
- 查询 API 的入参支持按标签筛选，出参包含标签；资源数量、ID、名称和跳转链接正确。
- 单个与批量绑定/解绑在多个入口结果一致。
- 按标签授权的子账号只能看到符合策略的资源。
- 资源销毁后，业务资源列表和标签关联视图均不再出现该资源；创建者系统标签也应解除绑定。
- 分账测试覆盖分账标签设置、账单标签展示、按标签汇总/筛选和下载结果。
