# 接入后生命周期变更

## 下线与地域变更

标签侧不能自行感知某类业务资源是否已彻底销毁。因此产品或地域下线前，必须以业务侧资源事实与标签库绑定记录交叉确认；标签库仍有记录时，应先处理存量绑定，再隐藏或下线配置。

新增地域的知识入口是 `4015828144`。下线地域还要区分资源真实销毁与仍在回收站，确认目标地域标签记录清空。地域从“区分地域”变为“不区分地域”不是简单配置修改，因为资源六段式中的地域段发生语义变化。

## 产品或资源更名

展示名称与资源身份不是同一个概念：

- 产品中文名、英文名通常可随产品字典调整；产品简称通常不可直接修改。
- 资源中文名、英文名通常可调整；`resourcePrefix` 是资源身份的一部分，不能当作展示名直接改写。

若 `serviceType`、`resourcePrefix` 或地域语义确需变化，存量资源必须迁移绑定关系。稳定迁移模型是“先新后旧”：

1. 用新六段式为存量资源绑定同一组标签。
2. 确认新记录可查、功能正常。
3. 使用原六段式解绑旧记录。
4. 再核对旧记录无新增或遗漏。

不能直接原地改六段式，因为已绑定记录的资源身份不可变。迁移窗口内可能出现暂时双写、无法解绑或新资源暂无标签关联等用户影响，具体顺序必须回源当前流程。
