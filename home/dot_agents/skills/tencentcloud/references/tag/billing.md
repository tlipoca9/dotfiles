# 分账标签与账单

## 生效模型

标签进入账单需要同时满足：产品支持标签、资源已经绑定标签、目标键被设置为分账标签，并且这些状态在账单出具前已经生效。账单生成时点和数据周期由计费系统决定，不能用当前标签状态倒推出历史账单一定相同。

分账通常不需要额外接入。默认情况下，标签侧 `serviceType` 与计费产品编码存在约定映射；只有两侧编码无法按默认规则对应，或计费量与资源 ID 存在拆分/聚合等特殊模型时，才需要计费侧维护特殊映射。

并非所有计费项天然可按资源标签分账。按流量、调用次数等非资源 ID 维度计费时，可能无法直接与标签资源身份关联；部分产品或结算类型还可能有独立限制。

## 异常知识

账单归属错误应区分三个边界：

1. 标签侧保存的资源六段式和键值是否正确。
2. 标签与计费产品/子产品映射是否正确。
3. 账单侧实际读取和展示的标签是否正确。

同一资源 ID 对应多个六段式时，错误或历史六段式可能被计费链路读取。`resourcePrefix=None`、未接入的 `serviceType` 或其他不规范六段式通常提示脏数据，但仍需业务侧确认正确资源身份。修正知识通常是先清除错误身份的绑定，再以正确六段式绑定，并由计费侧确认特殊映射或缓存数据。
