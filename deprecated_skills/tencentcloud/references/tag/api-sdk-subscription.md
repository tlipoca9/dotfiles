# Tag API、SDK 与订阅

## API 与控制台 SDK 的边界

云产品后端通过 Tag 云 API 完成绑定、解绑和查询；云产品控制台优先使用统一标签 SDK/组件提供选择、展示、筛选和编辑体验。SDK 的批量编辑组件会自行调用标签云 API，使用方不应重复提交相同写操作。

创建资源 API 应能接收标签；资源查询列表和详情 API 应返回标签；列表 API 应支持按标签筛选。删除资源时必须同步解除资源标签，否则标签库会保留销毁资源的绑定记录。

SDK 能力和前端参数会演化。标签策略按具体产品/资源类型生效时，SDK 调用需要正确提供 `serviceType` 和 `resourcePrefix`；具体字段、组件方法和当前支持能力必须读取 SDK 原文 `447415805`。

## 标签数据订阅

业务侧只有在复杂本地查询或跨地域低时延确有需要时才保存标签副本；不应默认复制数据。

订阅模型：Tag 服务按订阅时提供的 `serviceType`、`region`、`resourcePrefix` 将增量变更发送到指定 endpoint。业务消费者必须覆盖订阅文档列出的所有增删改消息格式。

订阅只解决增量：如果产品已经产生标签数据后才开始订阅，需要另行初始化存量数据。消息链路还需要实时或离线对账来发现丢失和漂移。
